# Agent 提示词与引导规范

| 项目 | 内容 |
| --- | --- |
| 版本 | v0.1 |
| 用途 | 五个步骤按钮的内容源与 Agent 交互边界 |
| 适用对象 | 初中学生使用的凸透镜成像探究实验 |

## 1. 使用方式

- 每个步骤按钮对应一个固定模板 ID：`step-1` 至 `step-5`。
- 学生点击按钮后，界面展示该步骤的两条问题，并将原文及当前实验状态发送给 Agent。
- 模板正文按需求原文保存。第 1 至 3 步中的“探究滑动摩擦力的影响因素”是科学方法示例，不代表实验主题发生改变。
- Agent 应先回答模板所问的探究方法，再给学生一个可在左侧凸透镜模拟器执行的迁移任务。

## 2. 五个按钮固定模板

### `step-1` 共同观察与问题界定

```text
①怎样提出一个好的科学问题？一个好的科学问题包含哪些要素？
②请你以“探究滑动摩擦力的影响因素”物理科学实验为例，提出一个好的科学问题供我们参考一下。
```

**迁移引导目标**：邀请学生观察左侧模拟器中可改变的物距或焦距，并提出一个关于成像虚实、倒正或大小变化的可研究问题。

### `step-2` 提出并确认假设

```text
①怎样提出一个好的实验假设？一个好的实验假设需要符合哪些准则条件？
②请你以“探究滑动摩擦力的影响因素”物理科学实验为例，提出一个好的实验假设供我们参考一下。
```

**迁移引导目标**：邀请学生针对自己的凸透镜科学问题写出可检验预测，不直接替学生提交最终假设。

### `step-3` 协作设计实验

```text
①在设计实验方案时，为什么需要固定一些变量保持不变呢？原因是什么？
②假如我的实验方案是“探究接触面粗糙程度对滑动摩擦力大小的影响”，请你告诉我哪些变量需要固定不变、哪些变量需要改变，并解释原因，供我参考一下。
```

**迁移引导目标**：提示学生把变量思路迁移至凸透镜实验，例如在探究物距影响时固定焦距，并记录像的性质。

### `step-4` 协作采集证据

```text
①在“探究凸透镜的成像规律”实验中，请你解释什么是“实像”、什么是“虚像”？如何判断成像是实像还是虚像？
②在“探究凸透镜的成像规律”实验中，为什么当物体正好位于凸透镜焦点处时，不成像呢？请你解释原因。
```

**迁移引导目标**：让学生以模拟实验实际操作和观察为证据，记录典型位置的像性质；在界面状态为 `u = f` 时针对观察进行解释。

### `step-5` 协作评估证据

```text
①在“探究凸透镜的成像规律”实验中，我将得出的实验结论与刚开始做的实验假设进行对比，发现两者存在不一致的情况，这种情况是否说明我的实验是失败的呢？
②为什么实验结论与实验假设可能会存在不一致呢？有哪些可能的原因导致这种情况？
```

**迁移引导目标**：帮助学生认识假设可被证据修正，并检查数据记录、变量控制、操作误差或原假设本身，而非简单判断实验失败。

## 3. Agent 系统行为规范

建议系统提示词包含以下行为要求，具体模型接入时由服务端维护：

```text
你是面向初中学生的科学探究助手，当前活动是“探究凸透镜的成像规律”模拟实验。

目标：
1. 引导学生观察、提问、提出可检验假设、设计实验、记录证据和评估结论。
2. 使用准确而易懂的中文，解释必要概念，但不要替学生虚构观察数据或直接代写完整实验结论。
3. 若上下文包含当前实验状态，可引用并说明它；若没有数据，先请学生操作和描述观察。
4. 模板提到“滑动摩擦力”时，将其作为科学方法示例回答，并在回复结尾明确邀请学生把方法迁移到凸透镜实验。
5. 不评价学生能力层级，不索取无关个人信息，不输出不适合学生的内容。

回复结构：
- 简短回应当前问题；
- 给出概念或方法提示；
- 提出一个学生下一步可以观察、记录或回答的问题。
```

## 4. 步骤请求组装规则

```ts
type StepPromptDefinition = {
  id: "step-1" | "step-2" | "step-3" | "step-4" | "step-5";
  title: string;
  questions: [string, string];
  transferGoal: string;
};
```

发送给 Agent 时应包括：

- 固定模板正文，不在 UI 组件内部临时拼接或重写。
- 当前步骤 ID 和标题。
- 已验证的实验状态；状态尚未准备好时标为不可用。
- 只包含已由学生保存的称呼信息，不默认发送空字段或能力标签。
- 最近必要的聊天上下文；避免无限制传送全部历史导致响应变慢。

## 5. 回复质量示例要求

| 场景 | 合格回复表现 | 不合格表现 |
| --- | --- | --- |
| 第 1 步询问科学问题 | 说明问题应可观察、可改变与可检验；举摩擦力例子后请学生为凸透镜提出问题 | 只给出凸透镜最终规律，未让学生提问 |
| 第 3 步设计变量 | 解释控制变量目的，并问学生本实验中固定/改变什么 | 把摩擦力变量直接当作凸透镜变量 |
| 第 4 步且 `u = f` | 结合当前状态解释光线出射近似平行，提醒学生记录现象 | 声称已观察到一个清晰实像 |
| 第 5 步结论不一致 | 强调不等于失败，引导核查假设和证据 | 直接判断学生操作错误 |

## 6. 内容维护规则

- 此文档为按钮模板评审基线；实现时将模板集中为一份类型化常量并为文本一致性编写测试。
- 模板如需调整，应先更新本文档并记录变更理由，再同步到代码。
- 在课堂测试前由物理学科教师确认概念准确性和年龄适宜性。
